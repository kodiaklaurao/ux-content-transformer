Content transformer

Add message, context, and goal, then generate strings. Use the copy buttons or select text yourself — paste it wherever it needs to go (prototype, message, ticket, doc, or anything else).

Message

What readers should know, think, or feel — the substance you want reflected in the final copy.

Context

Copy type, UI limits, placement, prior step, last action and label, likely mindset — anything that changes length or tone.

Goal

Desired next action in the product: the concrete task or decision (drives primary button / CTA line).

Optional

Draft — existing or rough text to fold in. Output format — what you need (e.g. modal + buttons, info box, Slack blurb, search placeholder). Shapes what blocks appear below.

Generated copy

Copy a section with the buttons, or highlight text in a box and copy it — then paste wherever you need it.

Figma-style labels

Structured labels and lines — easy to drop into a design file or spec.
