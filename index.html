Content transformer

Add message, context, and goal. The model rewrites your notes into microcopy using the style guides in this repo (same idea as asking ChatGPT or Claude, but with your team rules baked in). Copy the result into a prototype, Slack, or anywhere else.

Message

What readers should know, think, or feel — the substance you want reflected in the final copy.

Context

Copy type, UI limits, placement, prior step, last action and label, likely mindset — anything that changes length or tone.

Goal

Desired next action in the product: the concrete task or decision (drives primary button / CTA line).

Optional

Draft — existing or rough text to rewrite. Output format — what you need (e.g. modal + buttons, info box, search placeholder). The model uses this to choose sections.

Generation

Microcopy is produced by OpenAI through a small Netlify function (browsers cannot call OpenAI directly). Host this repo on Netlify, add OPENAI_API_KEY in site settings, or paste your key below — it is only sent to your Netlify function and OpenAI, not stored on this page.

Leave blank if this site is served from Netlify (same domain). On GitHub Pages, paste your Netlify deploy URL once — it is remembered in this browser.
